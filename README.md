## How to start using Julia

Follow [these instructions](https://code.visualstudio.com/docs/languages/julia) to install Julia and set up the Julia extension in Visual Studio Code.

Once setup is complete, open the command palette in VS Code and run `Julia: Start REPL`. This starts an interactive Julia session in the terminal.

For more setup guidance, including optional Jupyter notebooks, see the [QuantEcon installation guide](https://julia.quantecon.org/getting_started_julia/getting_started.html).
